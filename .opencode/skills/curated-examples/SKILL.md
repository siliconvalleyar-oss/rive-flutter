# Curated Rive-Flutter Examples

This branch (`curated-examples`) contains a hand-picked selection of the most useful Rive-Flutter example features, stripped of noise.

## Selected Features

| Section | Features |
|---|---|
| **Getting Started** | Shared Texture, Manual Shared Texture Management |
| **Rive Features** | Audio |
| **Asset Loading** | Network .riv Asset, Out-of-band Assets, Out-of-band Assets - Audio, Out-of-band Assets - Cached |
| **Painters [Advanced]** | Single Animation Painter |
| **Flutter Concepts/Integration** | Flutter Ticker Mode, Flutter Time Dilation |
| **Legacy Features** | Inputs [Nested], Text Runs [Nested] |

## What Was Removed

- Basic/trivial examples (Rive Widget, Rive Widget Builder)
- Demo Scripting, Data Binding (all variants), Responsive Layouts, Events
- State Machine Painter, Centaur Game
- Pause/Play, Hit Test, Transform, Multi Touch
- Performance/Memory testing section
- All commented-out entries
